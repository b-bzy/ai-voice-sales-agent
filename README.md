# AI 语音外呼销售 Agent

> 新加坡某 AI 语音创业公司 · AI 产品经理 · 2026.01 – 2026.08
> 面向金融行业与海外电商的 AI 语音外呼产品，从 0 到 1 建设

---

## 一、项目背景

海外电销与金融客服场景高度依赖人工外呼：坐席成本高、跨时区排班困难、话术质量不稳定、单量难以规模化。团队判断大模型语音能力已经具备接管标准化外呼流程的可行性，决定自建面向金融行业与海外电商客户的 AI 语音外呼产品。

我在其中承担客户端产品设计与模型端优化两条线的产品工作。

## 二、我的角色与职责

作为 AI 产品经理，负责产品侧从需求分析到 MVP 验证闭环，以及自研语音模型的评测与数据侧支持。

### 1. 外呼产品 0 → 1 设计

- 分析海外企业外呼需求，拆解目标客户（金融行业、跨境电商）的真实作业场景与合规约束
- 负责终端系统信息架构设计，定义 MVP 验证闭环：**取任务 → 拨号 → 对话 → 落库**
- 搭建问卷测评台，招募母语（native speaker）测试团队，让效果评估脱离团队内部的主观判断

### 2. AI 调优评测体系

参与搭建三维评测体系，把「这个 AI 像不像人、稳不稳、能不能成单」拆成可度量的指标：

| 维度 | 关注问题 |
|---|---|
| 拟人度 | 语气、停顿、打断处理是否接近真人坐席 |
| 稳定性 | 长对话是否跑题、是否幻觉、异常输入下是否可控 |
| 转化率 | 最终是否达成业务目标（加微、留资、成单） |

### 3. 自研全双工语音模型

外采 API 存在**成本高、效果差**两个硬约束，团队决定自研。

- 基于前期业务积累的原始通话数据，参与电销场景**全双工语音模型**自研（与高校联合研究）
- 搭建外语测试团队，支持数据标注与后训练方向制定
- 建立 bad case 收集机制，把线上暴露的问题回流为训练与迭代输入
- 推动自研模型落地替代外采 API

## 三、关键设计取舍

- **为什么是全双工**：电销场景中客户随时打断、抢话是常态，半双工（说完再听）的交互会显著拉低拟人度与转化率
- **为什么先建评测台再调模型**：语音效果的主观性极强，没有可复现的评测口径，调优就会退化成团队内部的口味之争
- **为什么招募母语测试团队**：面向海外市场，非母语者对语气自然度的判断不可靠

## 四、成果

- 参与该语音产品从 0 到 1 建设，跑通完整 MVP 验证闭环
- 建立拟人度 / 稳定性 / 转化率三维 AI 调优评测体系
- 推动电销场景全双工自研模型落地，替代高成本外采 API
